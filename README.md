# OptiGTA5RP

FPS optimization toolkit for GTA V RAGE MP servers.

Features:
- Windows gaming optimizations
- GTA V config tuning
- RAGE MP cache optimization
- background process cleanup
- latency and frame pacing tweaks
- safe reversible scripts

## Structure

`optimizer.ps1` - main optimizer

`configs/` - GTA V recommended configs

`backup/` - created automatically before changes
